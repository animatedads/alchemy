# Order — Control to Alpha
Alpha, ваше завдання — вести пошук у районі Sydney Opera House. Виконайте обліт за годинниковою стрілкою та огляньте прилеглу акваторію.
# Order — Control to Bravo
Bravo, прямуйте до Blues Tower. Проведіть візуальний огляд верхньої секції та навколишніх територій.
# Order — Control to Charlie
Charlie, ваша зона — Circular Quay. Працюйте від східного причалу до західного, стежте за рухом на воді та береговій лінії.
# Order — Control to Delta
Delta, здійснюйте пошук у районі Observatory Hill. Після цього прямуйте до Harbour Bridge. Окремо огляньте північний пілон (North Pylon) та південний пілон (South Pylon).
# Order — Control to Delta
Delta, огляньте північні пілони.
