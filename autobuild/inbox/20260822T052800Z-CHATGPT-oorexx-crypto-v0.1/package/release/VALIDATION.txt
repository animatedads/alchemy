Defects found by the new independent battery
--------------------------------------------
The inherited ChaCha20 implementation claimed RFC 8439 semantics but did not
match the RFC vector. v0.1 fixes both causes:
1. key/nonce 32-bit words are now decoded little-endian;
2. the 16-word working state is copied explicitly. In ooRexx, `x. = s.` aliases
   stems rather than making the independent working-state copy ChaCha requires.
The RFC 8439 vector passes after these corrections.

The inherited X25519 encryptStream/decryptStream wrapper does not provide a
standards-defined construction and does not round-trip arbitrary strings
cleanly. It is therefore explicitly outside the supported v0.1 security
surface. X25519 key-agreement arithmetic is tested independently.

The inherited Ed448 helper is likewise not represented as RFC 8032 Ed448: the
source uses SHA-512 where standard Ed448 requires SHAKE256. It remains
experimental/unsupported. RSA helpers remain textbook/reference RSA without
modern padding. MD5 is compatibility-only.
