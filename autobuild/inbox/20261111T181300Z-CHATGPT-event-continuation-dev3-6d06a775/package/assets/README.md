Place the seven compatible ooRexx/WASM web runtime files from the official
JosepMariaBlasco/oorexxwasm Web pages release together in this directory.
See ../README.md and https://github.com/JosepMariaBlasco/oorexxwasm/releases

Required: ooRexx.js, ooRexx-worker.js, rexx.js, rexx.wasm, rexx.data,
js-realm.js, polygon-clipping.umd.min.js.

The upstream runtime is not reimplemented or bundled in this prototype.
