01 / 02

What the preview actually does

The generated pages contain local HTML, CSS, JavaScript and a favicon. Mobile navigation uses local browser state only; the preview does not submit information or load third-party services.

  • No embedded analytics
  • No public-facing account signup
  • No form collection
02 / 02

What changes on a live host

An HTTPS server naturally processes network requests and may log technical events. Its real logging, retention, access, authentication and data handling need to be documented against the deployed configuration before the production privacy page is approved.

  • Publish a verified operator identity
  • Declare actual retention and contact
  • Review access and incident procedures
