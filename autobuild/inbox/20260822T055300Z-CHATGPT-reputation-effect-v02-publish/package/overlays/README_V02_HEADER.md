# Reputation Effect v0.2

Reputation Effect v0.2 supersedes v0.1. It retains the geographic, temporal, evidence-bearing reputation model and adds first-class customer/public communication surfaces.

The v0.2 API is `reputation.effect/0.2`. New communication evidence includes unresolved failures, communication acts, declared intent, route redirection, evidential limits, process ownership, retractions and corrective statements. Deterministic assessment codes include `COMMERCIAL_PRESSURE_COLLISION`, `PROCESS_CIRCULARITY`, `DECLARED_INTENT_ACTION_MISMATCH`, `COMMERCIAL_RESTRAINT`, `EVIDENTIAL_DISCIPLINE`, and `REPUTATIONAL_RECOVERY`.

Publication of this tree is gated by the component regression suite and by Shannon reputation gate, communication and feed integration under Alchemy Autobuild v0.4 per-test environment contracts. See `AUTOBUILD_PROVENANCE.md` and `VALIDATION.txt`.
