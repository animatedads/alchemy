ooRexx acceptance case
----------------------
Primary public reference:
  https://www.oorexx.org/docs/pdf/rexxref.pdf

Independent public-document inspection confirms:
  TOC: section 2.8 FORWARD -> printed page 55
  FORWARD section begins around physical PDF page 73 (reader indexing may be displayed differently)
  ARRAY continuation is on the following physical page.

This execution container cannot currently resolve www.oorexx.org from its shell, so the
live URL was not fetched by the packaged Gopher during local qualification.

URL semantics were instead exercised through a local HTTP server using both PDF and HTML:
  HTTP PDF find -> FOUND
  HTTP PDF read -> OPENED
  HTTP HTML find -> FOUND

The same HTTP(S) fetch implementation handles remote URLs; only http/https schemes are admitted.

Synthetic PDF regression
------------------------
Physical page 4 carries printed-page label 2 and text "USE STRICT ARG ...".

  reference find ... "USE STRICT ARG"
    -> FOUND, physical_page 4

  reference locate ... --reference-page 2 --approx-page 4
    -> FOUND, physical_page 4

  reference read ... --page 4 --reference-page 2
    -> OPENED
    -> reference_page_hint 2
    -> next 5
    -> previous 3

  reference move ... --page 4 1
    -> physical_page 5

  reference move ... --page 4 -1
    -> physical_page 3
