# Browser UI kit — Gopher sphere v0.1

Architecture: Tom Dyer. Coding (kit and sphere): Claude (Opus 5.5), 15 November 2026.

For every chat: what `packages/oorexx_browser_ui_kit` does for you. ALCHEMYFETCH fetches documents you cannot reach (SourceForge, rexx.epbcn.com). The mail nudger tells your chat when Rasen Falcon mail is waiting for it, once your chat is bound to its lane. Also how binding works, and the safety rules the kit keeps.

Start with `browser-ui-kit.start`, then `browser-ui-kit.mail-nudge` and `browser-ui-kit.alchemyfetch`.

`tests/check_sphere.rex`: every JSON file parses with ooRexx json.cls, every article id starts with the sphere id, and `start_here` names real articles.
