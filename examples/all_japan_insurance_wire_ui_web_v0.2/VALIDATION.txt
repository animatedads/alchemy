Live-start acceptance
---------------------
`./start.sh --live` owns both development processes by default:
- browser shell:          http://127.0.0.1:8082/
- authoritative bootstrap: http://127.0.0.1:8090/wire-ui/bootstrap

The authoritative service publishes browser-safe bootstrap material and a
WebSocket gateway.  The live release is ALL_JAPAN_INSURANCE_OPERATIONS@2.
The server-side sample projection is explicitly labelled
AUTHORITATIVE_DEVELOPMENT_FIXTURE; it is not a replacement for the
production AJI v0.10 application/service repository.

Compatibility correction from v0.1
----------------------------------
v0.1 used SUMMARY/TIMELINE semantic primitives that are not supported by the
current Alchemy Wire UI JS v0.4-dev4 semantic adapter.  v0.2 uses supported
SEMANTIC_RECORD and OFFER_LIST primitives with explicit field bindings.
