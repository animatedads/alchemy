# Contract invariants

- A relationship between legal entities is not a security interest.
- `collateralProvider` must match the Core-confirmed asset owner.
- Merchant Banking cannot increase the controlled amount returned by Core Banking.
- Control requires explicit Legal Effect and Institutional Policy provenance on the request.
- An accepted Core control decision must identify the Core authority and encumbrance.
- Realisation requires a prior default/close-out reference and Legal Effect evidence.
- An accepted realisation returns a Core settlement reference; the Merchant Bank does not post the Core Ledger itself.
