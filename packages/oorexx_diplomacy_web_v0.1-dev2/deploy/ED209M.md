## activation gates

1. Resolve target identity by authenticated host inventory, exact existing
   TLS listener and authorized service identity. Confirm no collision with
   existing sites/roles. Provision certificate for exact FQDN with approved
   certificate lifecycle and listener/route ownership. No public DNS cutover
   or change to the existing apex role in this package.
2. Public accounts need explicit isolated identity realm and verified
   registration/recovery, revocation, CSRF, same-origin and rate control.
   Resolve principal server-side on every bootstrap; bind unique session,
   application, AP and least-privileged queue principal. The native
   DiplomacyWireIngress adapter must be the only inbound dispatch route.
   Revoke and purge old AP queues/session on logout and identity change.
   No credential/key privileges are inherited from estate administration.
3. Provision private persistent database for account, membership, immutable
   sealed profile, runner record and game state. Per game allocate a fresh
   exclusive run directory mode 0700, umask 077, named by host not request;
   store canonical .log and .operator.log files there. Never overwrite or
   serve raw logs. Worker uses a trusted config and seed and projects only
   committed events. On loss of process, fail closed; idempotent restart/rejoin
   and replay from durable checkpoint still need implementation and tests.
4. Human worker availability and actual elapsed limits are proven locally,
   but exact production phase timing is an explicit game policy. Current
   dev7r1 callback order is sequential; each participant gets its own bounded
   wait, not a common simultaneous deadline. No change to controller lane.
   Qualify simultaneous scheduling if desired with upstream controller work.
5. Approve encrypted credential storage with Secret Broker v0.2 opaque handles
   and lease semantics (not itself a vault). A dedicated authenticated secret
   inlet receives API keys, not Wire actions or browser storage. Per-user exact
   model ID and spend budget consent; scoped lease to approved provider endpoint.
   No key or raw provider response leaks to player or public logs; run hostile
   cross-user credential tests before live call. Designer submits the same
   sealed 15-member source bundle to each admitted model. No paid calls are
   authorised by this package.
6. Test public registration, real isolated multi-session WSS, TLS and session
   teardown/expiry, persistent/reboot recovery, all-human full game policy,
   independent mixed/LLM runners, prompt designer, no cross-seat/instruction/
   private-press leakage, rate limits, error feedback, browser desktop/mobile
   and accessibility. A local stage is not public admission.
