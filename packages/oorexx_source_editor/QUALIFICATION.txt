Dev5 qualification:
  - SourceCompletionCandidate carries label, kind, detail, path, line and insertion text.
  - SourceCompletionProvider completes document symbols and source-tree files as reusable ooRexx objects.
  - completion order is deterministic and independent of Directory iteration.
  - CLI/UI/MCP may project the same completion objects; terminal text is not the authority.
  - Semantic Source Store / Development Desk remains authority for semantic object creation and materialisation.
  - SourceDocument remains authority only for conventional materialised-file inspection/editing.

Platform alignment:
  - recursive traversal uses RexxUtil SysFileTree.
  - regex uses ooRexx RegularExpression.
  - no Python implementation files.
  - no external find/grep subprocess in source-tree search.
  - save retains exact-generation fencing and backup but makes no crash-durable atomicity claim; Atomic File remains the intended publication authority.

Dogfood:
  - completion classes, CLI commands, tests, README, manifest and qualification were edited through SourceDocument generation-checked saves.
  - final source was self-searched, self-completed and validated under the supplied r13196 runtime.

Known CLI limit:
  the ooRexx launcher flattens the script command tail; the current small CLI parser cannot faithfully recover shell grouping for arbitrary multi-word patterns. The object API has no such restriction.
