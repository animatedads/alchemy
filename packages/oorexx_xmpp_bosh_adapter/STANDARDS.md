# Standards

- XEP-0206 — XMPP Over BOSH: binding of XMPP stream establishment/restart and stanza traffic to BOSH.
- XEP-0124 — supplied by the separate generic BOSH transport package.
- RFC 6120 — supplied by the Messaging & Presence XMPP session engine.

This package does not implement MUC, PubSub, file transfer, avatars or other XMPP extensions.
