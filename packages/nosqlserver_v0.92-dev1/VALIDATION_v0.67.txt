NoSQLServer v0.67 validation
============================

Focus
-----
Read-only GeoPackage backend and heterogeneous federation.

Implemented
-----------
- GeoPackageDatabaseEngine
- GeoPackageDatabaseTable
- automatic discovery from:
    gpkg_contents
    gpkg_geometry_columns
    PRAGMA table_info
- automatic NoSQLServer TableDefinition construction
- GeoPackage POINT/POLYGON/MULTIPOINT/etc BLOBs preserved as typed
  GeoPackageGeometry values carrying geometry type and SRID
- direct ordinary NoSQLServer SELECT/WHERE/ORDER BY/LIMIT over GeoPackage tables
- FederatedDatabaseEngine can register arbitrary external read engines using
  addEngine(), while retaining FILE and OBJECT sources
- joins can therefore cross independent GeoPackage files
- read-only bridge uses SQLite itself through tools/gpkg_bridge
- bridge source and rebuild script are included; the bundled binary is the
  Linux x86_64 test build and can be rebuilt with:
      tools/build_gpkg_bridge.sh

Deliberate v0.67 boundary
-------------------------
Geometry is typed and preserved, but ST_WITHIN/ST_INTERSECTS/ST_DISTANCE are
not yet SQL functions. v0.67 proves the backend/catalog boundary first.
GeoPackage mutation is not exposed.

Portable regression fixture
---------------------------

containing real sample POINT/POLYGON blobs and related-address rows from the
provided Inverness datasets. It proves schema discovery, typed geometry,
ordinary SQL, and federated joining without requiring the full source datasets.
