v0.69 compatibility delta
-------------------------
- Database Core compatibility facade extended to the v0.34 relational-source
  and table-source observable contract using the existing namespaced
  NoSQLDatabaseCore* family.
- DatabaseType gains GEOMETRY.
- geometry column metadata retains geometryType and SRID.
- Database geometry values retain raw payload, subtype, SRID and encoding.
- GeoPackage metadata now reports the geometry column's subtype and SRID.
- Federated tableMetadata delegates to the owning provider where available,
  preserving provider metadata instead of rebuilding a lossy generic shape.
- DB Core adapter advertises TABLEDISCOVERY and SPATIALTYPES honestly.
- SPATIALFUNCTIONS remains absent; no ST_* predicate is faked.
- GeoPackageDatabaseEngine~version no longer references nonexistent
  .DatabaseVersion; it returns native NoSQLServerVersionInfo.

Known historical harness issue
------------------------------
tests/v061_torture_harness_smoke.rex asserts that foreign-key DDL must be
rejected because FK enforcement is absent. That assertion predates the later
FK implementation and now fails on the accepted untouched v0.68 as well as on
v0.69. It is therefore not a v0.69 regression and is not treated as a current
acceptance gate.

External-data note
------------------
tests/v067_geopackage_live_smoke.rex reports SKIP because the two original full
Inverness GeoPackage source datasets are not mounted at the hard-coded paths in
this runtime. The bundled portable GeoPackage fixture smoke and the new v0.69
geometry/federation smoke both pass and rebuild/use the included bridge.
