NoSQLServer v0.39 validation
============================

Focus
-----
Native INSERT grammar compatibility exposed by an external MariaDB/MySQL client.

New SQL surface
---------------
- INSERT INTO table VALUES (...) positional form.
- Positional values map to TableDefinition declared column order.
- Explicit-column INSERT accepts spaces, tabs, LF and CRLF between grammar tokens.
- INSERT dispatch accepts SQL whitespace between INSERT, INTO and the table name.
- Multi-row positional INSERT is supported.
- Parentheses around every VALUES tuple remain mandatory.
- Quoted whitespace is preserved as data; the parser does not globally collapse SQL text.

Capabilities
------------
- INSERT_POSITIONAL_VALUES
- INSERT_FLEXIBLE_WHITESPACE
