Scope
-----
v0.74 replaces the GeoPackage C/SQLite helper transport with a native ooRexx
SQLite 3 binary storage reader and exposes the same storage reader as a generic
read-only SQLite relation provider.

No runtime SQLite library, helper executable, Python process or C process is
used by the v0.74 SQLite/GeoPackage providers.

Storage boundary
----------------
Implemented:
  SQLite 3 header and page sizing
  table b-tree interior/leaf pages
  SQLite varints
  rowids
  record serial types NULL/integer/REAL/TEXT/BLOB
  overflow payload chains
  UTF-8 text
  ordinary rowid table schema and rows

Explicitly unsupported in v0.74:
  mutation
  WAL / rollback-journal replay
  WITHOUT ROWID payload reads
  virtual table implementations
  UTF-16le / UTF-16be text
  SQLite VM / trigger execution
  index-btree query execution

These surfaces fail or remain unadvertised rather than being guessed.
