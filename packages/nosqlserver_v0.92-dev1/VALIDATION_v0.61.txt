NoSQLServer v0.61 validation
============================

Focus
-----
SQL DELETE ... USING with one source relation.

Semantics
---------
Supported shape:
  DELETE FROM target [alias]
  USING source [alias]
  WHERE predicate

- Target and source aliases are resolved through SQLAliasRelationDefinition.
- WHERE is evaluated against the combined target/source row.
- A target row is selected for deletion if at least one USING row satisfies the
  predicate.
- Duplicate USING matches do not delete the target more than once and do not
  inflate affected-row count.
- Deletions are applied after candidate discovery through the target primary key,
  so scanning is not invalidated by in-loop mutation.
- Target tables without a primary key are cleanly SQLUNSUPPORTED.
- v0.61 supports one USING relation only.

Hell Corpus v2 Q22
------------------
  DELETE FROM timesheet t
  USING emp e
  WHERE t.emp_id = e.emp_id
    AND e.active = FALSE
    AND t.billable = FALSE

The seed has one matching row:
  timesheet entry 10 -> emp 9, inactive, non-billable

Independent smoke also verifies:
- exact surviving target rows;
- duplicate source matches delete one target exactly once;
- non-matching source rows leave the target unchanged.
