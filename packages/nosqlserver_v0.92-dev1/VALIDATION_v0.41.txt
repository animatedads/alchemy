NoSQLServer v0.41 validation
============================

Focus
-----
Native SELECT LIMIT/OFFSET compatibility for external SQL clients.

New SQL surface
---------------
- LIMIT count
- LIMIT count OFFSET offset
- MySQL-compatible LIMIT offset,count
- LIMIT is applied after the complete SELECT/ORDER BY/set-operation result.
- LIMIT 0 returns an empty successful result.
- OFFSET beyond the result returns an empty successful result.
- Negative/non-integral LIMIT/OFFSET values are rejected.
