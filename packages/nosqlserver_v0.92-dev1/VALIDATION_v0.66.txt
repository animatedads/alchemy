NoSQLServer v0.66 validation
============================

Focus
-----
SQL OLAP grouping families:
- GROUPING SETS
- ROLLUP
- CUBE

Architecture
------------
The existing aggregate executor remains authoritative. OLAP clauses are parsed
into an ordered array of ordinary grouping sets and each set runs over the same
already-filtered source rows.

Semantics
---------
- GROUPING SETS preserves declaration order internally, then the query's ORDER BY
  orders the combined output.
- ROLLUP(a,b,...) expands to successive prefixes:
    (a,b,...), (a,...), ..., ()
- CUBE(a,b,...) expands to every subset of the dimensions.
- Dimensions absent from a particular grouping set project SQL NULL.
- The empty grouping set produces the grand-total row.
- On empty input the empty grouping set still returns one aggregate row
  (COUNT(*) = 0, SUM(...) = NULL).
- Duplicate grouping sets deliberately produce duplicate aggregate rows.
- OLAP grouping dimensions currently require resolvable columns.
- GROUPING()/GROUPING_ID() functions are not added by this release.
