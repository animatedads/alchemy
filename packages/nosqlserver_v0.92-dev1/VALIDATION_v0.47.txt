============================

Focus
-----
VALUES table constructors as relational sources, prompted by Grok Hell Corpus v2.

New SQL surface
---------------
- (VALUES (...), (...)) AS alias(column, ...)
- VALUES sources participate as virtual relations.
- VALUES may act as the left/base side of LEFT JOIN.
- Existing LEFT JOIN null-extension semantics apply unchanged.
- Literal typing/null handling is reused from the native SQL literal path.
- No physical storage object is invented for VALUES rows.
