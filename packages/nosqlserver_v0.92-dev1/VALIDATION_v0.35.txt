NoSQLServer v0.35 validation
============================

Focus
-----
Partition-wide window aggregates and derived-window filtering.

New semantics
-------------
- COUNT/SUM/AVG/MIN/MAX OVER (PARTITION BY ...) without ORDER BY evaluate over
  the complete partition.
- OVER () evaluates over the complete result partition.
- Ordered running aggregates retain their explicit ROWS BETWEEN UNBOUNDED
  PRECEDING AND CURRENT ROW requirement.
- Ordered ranking windows may coexist with partition-wide aggregate windows.
- Derived SELECT parsing uses top-level ORDER BY detection so ORDER BY inside
  OVER(...) does not truncate the outer query.
- Derived output names follow SQL output naming (qualified source names become
  unqualified derived columns unless explicitly aliased).
- Derived WHERE supports scalar arithmetic comparisons over projected/window
  values.
