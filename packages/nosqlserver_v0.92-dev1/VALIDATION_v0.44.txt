NoSQLServer v0.44 validation
============================

Focus
-----
Native database event registry plus first safe foreign-key subset.

Database events
---------------
- Runtime-scoped per canonical database root.
- BEFORE_INSERT / AFTER_INSERT
- BEFORE_UPDATE / AFTER_UPDATE
- BEFORE_DELETE / AFTER_DELETE
- Object handlers register with db~events~on(eventType, tableName, handler).
- Wildcard table registration is available with "*".
- BEFORE handlers may veto before authoritative storage/journal publication.
- AFTER handlers are observational and cannot retroactively undo publication.
- Registrations can be disabled with db~events~off(registration).

Foreign keys
------------
- Inline single-column REFERENCES syntax.
- FK metadata persists in table.yaml and is reconstructed on engine reopen.
- Parent target must be a single-column PRIMARY KEY or UNIQUE constraint.
- Child and parent column types must match.
- NULL child values are permitted.
- Child INSERT/UPDATE validates parent existence.
- Parent DELETE is RESTRICT/NO ACTION while referenced.
- Parent key UPDATE is RESTRICT/NO ACTION while referenced.
- Invalid FK declarations fail before child table publication.
- CASCADE / SET NULL / SET DEFAULT are deliberately SQLUNSUPPORTED until the
  staged multi-table mutation graph can publish them atomically.

Capabilities
------------
- DATABASE_EVENTS
- MUTATION_EVENT_VETO
- FOREIGN_KEYS
- FOREIGN_KEY_RESTRICT
