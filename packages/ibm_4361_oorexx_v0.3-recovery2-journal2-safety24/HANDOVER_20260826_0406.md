## Architectural boundaries that must remain separate

- **Freeze files** are durable, externally verifiable whole-machine evidence/replay artifacts.
- **Journal-pointed state** is live in-process history for rewind/fork/diff/retry.
- A journal may reference a freeze checkpoint as a base, but the journal does not replace or redefine the freeze format.
- The guest-visible **IBM 3215 channel console** is separate from the physical **IBM 4361 operator/control console**. The 3215 participates in guest channel I/O; the physical operator surface owns LOAD/IPL/START/STOP/status.

## Proven since safety1

### EX sequencing repair
The System/370 `EX` implementation was wrong after executing a normal target instruction: it continued at target+target-length rather than at the instruction after EX. This caused IEAIPL to copy only the first 256-byte block of its relocation area.

Correct behavior now:

- transient target bytes are executed without altering the template;
- ordinary target fall-through resumes at EX+4;
- a genuinely taken branch by the executed instruction still wins;
- focused `test_cpu_ex_sequencing.rex` is retained.

Real-MVT evidence proved loader work field C38=`0000162C` survives relocation after this correction.

### 3330 multitrack Read Count / Set File Mask
The old reconstruction raised File Protect immediately when multitrack READ COUNT (`92`) was issued under `SFM 58`. Hercules 2.17.1 behavior is to read all count fields on the current track normally and raise File Protect only when EOT would require a prohibited multitrack advance.

After correction MVT stopped scanning the entire volume to 403/18 and instead found the wanted record on CCHH 2/3, record 27, then entered the high-memory loader path.

### PACK corrected
System/370 `PACK` was corrected so every zoned source byte contributes its digit and the rightmost source zone nibble becomes the packed sign.

Real-MVT console-selection evidence preserved in `evidence/mvt_console_acceptance.log`:

- UCM `0C0` -> packed `0C0F` -> TIO 00C0 -> CC3 (master console not attached)
- UCM `01F` -> packed `01FC` -> TIO 001F -> CC0 (3215 attached)

The earlier deliberate WAIT 7 (`NO CONSOLE`) future therefore disappears for the correct reason.

### Exact LPSW sequencing
A newly loaded PSW is no longer modified by the old instruction's ILC bookkeeping. The operand wait PSW is loaded exactly.

### IBM 3215 guest console
A real guest-visible 3215 channel device exists separately from the physical 4361 operator console. Implemented command contract includes:

- 01 WRITE no CR
- 09 WRITE auto CR
- 03 NOP
- 0A READ INQUIRY (pending-read capable)
- 0B alarm
- 04 SENSE
- E4 SENSE ID = FF321500321500

READ INQUIRY state is intended to participate in live journal history; do not collapse this into the physical operator console.
