Known dev1 limits:
- Content bytes use injected WebDavMemoryContentStore by default. Provider-backed
  StorageByteSource/StorageByteSink streaming is intentionally deferred.
- Collections are DAV gateway metadata because Storage Fabric dev13 namespace
  bindings do not model directory inode objects.
- PROPPATCH/COPY/MOVE/LOCK/UNLOCK/REPORT and HTTP Range are not implemented yet.
- No claim is made that dev1 is a complete RFC 4918 implementation.
