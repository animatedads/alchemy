# Product scope

MVS Alchemy Services is a learning and compatibility environment for MVS 3.8j. It does not convert MVS 3.8j into z/OS and does not contain IBM DB2, IBM MQ, IBM LDAP, CICS, RACF, or other IBM licensed products. MAS provides deliberately limited compatible programming personalities backed by Alchemy services, allowing applications and students to exercise selected enterprise programming models on an accessible MVS system.
