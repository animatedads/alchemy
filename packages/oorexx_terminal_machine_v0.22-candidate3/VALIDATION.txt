v0.21 scope
-----------
Added TerminalEmulatorOrchestration.cls above the v0.20 exact-token execution
boundary:
  - fixed instruction FETCH -> DECODE -> EXECUTE orchestration;
  - fixed one-phase non-instruction event handling;
  - checkpoint before every accepted handler attempt;
  - exact execution ticket retained only inside the orchestrator;
  - automatic rollback on failed TerminalResult or trapped ooRexx SYNTAX;
  - linked explicit retry only from retained ROLLED_BACK attempts;
  - bounded immutable/value-free event-history evidence;
  - handler marker/method validation before checkpoint creation;
  - no arbitrary caller-supplied handler method names.

The orchestration layer remains local EMULATOR / TESTBED / REPLAY_SANDBOX
machinery. It adds no authority over TN5250LiveSession, TerminalSessionOwner,
broker/service capabilities, credentials, WLU admission or IBM i host state.
