# Changelog

## 0.1-dev1 — 2026-10-29
- New fail-closed JSON-RPC HTTPS route adapter for existing ooRexx HTTPS Server.
- Explicit public operation->RPC core service/method registration and publication freeze.
- Trusted identity attestation bound to request ID, TLS generation and accepted peer address.
- Per-invocation authorization including JSON-RPC batch/notification paths.
- Bounded request body, method/content-type/content-encoding validation and no-cache responses.
- Source checks and ooRexx fixture; runtime/interoperability validation is not yet claimed.
