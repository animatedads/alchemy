# ooRexx Android JNI proof v0.1-dev22-fixed

This package publishes the Android JNI proof APK supplied with the ooRexx
Android integration work.

The APK is retained as a binary release artifact because it is the directly
installable Android test deliverable. Its unpacked manifest and native payload
remain inside the APK; source for the JNI proof belongs in the corresponding
Android development package when supplied.
