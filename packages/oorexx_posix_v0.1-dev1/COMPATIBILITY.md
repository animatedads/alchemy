# Compatibility

API id: `oorexx.posix/0.1`.

Dev1 is additive and intentionally incomplete. Strong coherent stat/lstat/readlink, nanosecond times, statvfs, fsync/fdatasync, ACL and descriptor-relative traversal are capability gaps rather than command-line fallbacks.
