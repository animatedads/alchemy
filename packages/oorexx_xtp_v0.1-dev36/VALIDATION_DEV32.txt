3. Independent security review (before commit)
  The first build passed P1-P13. The reviewer confirmed ten defects by running probes, and
  reported two more from reading. All are fixed; the table with fixes and tests is in
  docs/SECURITY.md, "Review". High: protection fell to none when keys expired (H1); key
  refresh was not atomic and a bad key left the table half-cleared (H2); LDAP with zero or
  partial results counted as working and removed the file keys (H3).
  The reviewer found nothing serious in: nonce and counter use, AAD coverage, downgrade,
  context binding, OpenSSL usage, the replay window, bounds checks, KeyTable locking.
  The fixes were tested (P14-P20, ooRexx 2b-4) but not reviewed a second time.

6. Harness fault found and repaired during this work
  While adding -lcrypto, an edit of tests/run_negative.sh by Claude produced a stderr
  redirection into the planner's liboperational_planner.a, which overwrote that build
  output in the local work tree (not in the repository). The first dev32 regression failed
  on it. The archive was rebuilt from unchanged sources with the planner's own Makefile,
  the script was repaired, and the final regression above ran on both.
