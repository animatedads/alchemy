# V5V and high-resolution evidence

Normal path:
source -> V5V VisionSurface -> Camera Behaviour / Line Assessment

Escalation path:
behaviour/line evidence -> VisionHighResolutionRequest
                         -> authoritative source region/time
                         -> VisionRegionMaterial
                         -> evidence consumer

The high-resolution path does not replace the V5V observation and does not
reinterpret it. It obtains additional source evidence for the same stable
region/time coordinates.
