# Changelog

## 0.1-dev1

- Initial provider-neutral Bluetooth object/runtime contract.
- Event-first discovery, connection, pairing, RSSI and GATT value model.
- Semantic UUID profile aliases resolved through `UNKNOWN`.
- Standard minimal GATT map using ooRexx `json.cls`.
- In-memory provider for deterministic qualification.
- Linux RFCOMM native transport via Foreign Runtime ABI metadata.
