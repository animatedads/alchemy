# Source provenance

This package was developed against the user-supplied ooRexx 5.3.0 r13196 runtime and the existing ooRexx API roll-up available in the working set.

No Google-, Microsoft-, GitHub- or Okta-specific logic is embedded in the core. External providers are represented by standards metadata, endpoints and JWT/JWKS authorities.

The RS256 qualification key in the test suite is generated test material and has no deployment authority.
