# MAS/MAIL pre5 qualification status

REFERENCE SEMANTICS, NOT LIVE MVS QUALIFICATION.

INBOX / INBOX-UNSIGNED visibility, opaque typed handles, bounded mailbox paging,
UIDVALIDITY + UID stale-generation rejection, bounded opaque body/attachment
byte transfer, and distinct signature/identity/EMAIL_SEND/egress gates.
