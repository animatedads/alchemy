# ooRexx Materials Library v0.1-dev1

Independent reusable material-property catalogue for Physics World, Rexx-tronics,
Parts and physical-manufacturing consumers.

The catalogue owns reference properties, conditions and provenance. It does not
own mechanics, thermal, fluid, optical, electrical or manufacturing behaviour.

Initial catalogue: 16 engineering/reference materials including copper,
6061-T6 aluminium, steels, brass, silicon, FR-4, glass, polymers, water and air.

Values are simulation/reference defaults, not certificates for a particular
supplier, batch, heat treatment, humidity state or manufacturing lot.
