# Methodology Specification Template

Use this template when adding a methodology to the open catalogue.

## Principle

State the physical/mathematical idea in one paragraph. Describe the observation mechanism, not a product/library implementation.

## Inputs

List semantic input kinds and their required coordinate/time authority.

## Outputs

List measurements, candidate reconstructions, hypotheses or visualizations. If reconstructive, identify support-map and uncertainty outputs.

## Assumptions

List assumptions which, if false, can invalidate the method.

## Failure modes

Include false-positive, false-negative, model-degeneracy, registration, timing and source-quality failures where relevant.

## Controls

Specify null/negative controls, parameter sensitivity, forward-model checks, cross-method checks and holdout requirements.

## Allowed claim

Write the strongest statement the output can support by itself.

## Forbidden claim

Write at least one common overclaim that the output may not make.

## Composition

List useful upstream/downstream methodology families and any known incompatibilities.

## Qualification envelope

Record media types, resolutions/sample rates, codecs, duration/window sizes, operating thresholds, runtime/package versions and source hashes used to qualify an implementation.
