Security / conformance boundary:
  The credential factory is deterministic for development reproducibility.
  This is NOT production entropy or key storage, and this package makes no FIDO
  certification or conformance claim. CTAP1/U2F, PIN/UV, reset/configuration,
  extension families, getNextAssertion and production attestation are not yet
  implemented and are not advertised.

Host-enumeration boundary:
  This environment exposes no /dev/raw-gadget / usable UDC, so actual Linux host
  enumeration as a FIDO HID device is not claimed. The Raw Gadget ABI provider
  remains load-qualified and the complete FIDO/HID/CTAPHID/CTAP2 semantic path
  is exercised through VirtualUsbMemoryProvider.
