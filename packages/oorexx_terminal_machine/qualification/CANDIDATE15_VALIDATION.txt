Terminal Machine v0.22-candidate15 validation note
Date: 2026-10-28

TRIGGER
=======
Independent CODEX-PC qualification under ooRexx 5.3.0 r13196 stopped on candidate13's
first s3270 reference regression with:
  FIELD_LENGTH:A0000:7<>8, FIELD_MISSING:A0008, FIELD_MISSING:A000D

ROOT CAUSE
==========
The fixture declared an 8-column row but encoded SF(c0=20) plus eight data bytes.
ReadBuffer(Ascii) defines SF as occupying one display position, so the fixture actually
consumed nine positions and shifted subsequent field addresses. The parser's field-length
calculation was not the cause.

CANDIDATE15 CORRECTION
======================
- Correct the positive fixture to SF + seven data cells for the first 8-column row.
- Count display positions on every ReadBuffer data line.
- SF/data/GE consume one position; SA consumes none.
- Require exactly columns positions per data line (S3270_ROW_WIDTH).
- Require exactly rows data lines (S3270_ROW_COUNT).
- Add explicit overfilled and underfilled row regressions.
