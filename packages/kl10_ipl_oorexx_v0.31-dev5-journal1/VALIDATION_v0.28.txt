Security / boundary checks
--------------------------
- KL10Console exposes no CPU, DTE, memory, or I/O-bus getter.
- KL10ConsoleKeyboard exposes no DTE getter.
- optional stateToken rejects stale actions before queue mutation.
- non-7-bit text is rejected instead of folded modulo 128.
- BREAK is explicitly unsupported because no DTE signal path is modeled.
- snapshots expose queued-input byte count but not queued-input contents.
- console facade state is not serialized separately; queued input remains
  ordinary KL10_DTE_STATE/4 and round-trips through KL10_STATE/1.
