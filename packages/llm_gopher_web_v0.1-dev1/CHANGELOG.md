# Changelog

## 0.1-dev1 — 2026-09-02

- First human-facing web explorer for LLM Gopher sphere collections.
- Live directory rescan for `/Downloads/current/sphere`-style collections.
- Embedded profile identity discovery with prefixed-ZIP support.
- Exact-ZIP activation through `gopher sphere load --override`.
- Human rendering for Gopher context, articles, capabilities, corpus search and typed lookup.
- Raw Gopher JSON view.
- Loopback-only default and deliberately read-only HTTP/Gopher surface.
- Self-test mode for live Gopher round-trip qualification.
