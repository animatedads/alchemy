## Execution gate

\`SlamComposer~run\` is exploratory and deliberately executes some known incompatible paths to observe failures. New \ \`admit\` and \ \`runAdmitted\` keep that experiment intact and offer a separate fail-closed entrypoint. A rejected path returns BLOCKED, an empty trace and no result, before calls. A compatible path may still fail on an unmodelled numerical or semantic precondition; compatibility is not a proof of success.
