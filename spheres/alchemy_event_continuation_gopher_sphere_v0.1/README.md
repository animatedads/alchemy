# Event Continuation — Gopher sphere v0.1

Development continuity, not production acceptance. Read `packs/event-continuation/00-sphere.json` and its `start_here` articles. This sphere complements the `browser-api-access`, `architecture-intentions` and `alchemy-autobuild` spheres: native watches and delivery receipts are separate from managed browser/network authority and from the LLM's request lifecycle.

The toy chat is deliberately isolated. It is not a supported interface to mutate ChatGPT conversations. A real-application action needs an authenticated capability, policy admission, operation-specific idempotency, audit linkage and verified completion.
