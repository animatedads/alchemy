# Work Load Units (WLU) Knowledge Sphere v0.12

This sphere provides grounded, evidence-based knowledge of the `work.load.units/0.12` authority.

## Core Axiom
**WLU is work, not money.** It is a dimensionless normalized amount of work.

## Key Concepts
- **Two Axes**: WLU (amount) and WLU/s (delivery capacity).
- **Hierarchical Budgets**: Non-additive constraints where a single reservation is checked against every ancestor.
- **Work Lifecycle**: Expected -> Ceiling -> Actual (Settled).
- **Admission Pattern**: Fail-closed sequence (Proposed -> Policy -> Assessment -> Reservation -> Evidence -> Settlement).
- **Logical Jobs**: Business obligations that may move through multiple implementation stages (fallback graph) under one budget.
