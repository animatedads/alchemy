# Social Media Gopher Sphere v0.2

Load as `social-media`. This is the continuity and authority map for the
**ooRexx Social Media Library dev7** and its CMS Brand Builder integration.

`ops.social.start`, `arch.social.dispatch-guard` and `ops.social.dev7-status`
are the recommended starting articles. 13 articles and two searchable corpora
cover social surfaces, interactions, publication, scoped capabilities, provider
adapters, outbox, CMS/brand evidence and current qualification.

The old dev6 ZIP and immutable source lock remain for historical article
provenance; new dev7 claims are independently tied to their source SHA-256
and member digests. Run `python3 tests/test_sphere.py` for static checks.

No document in this sphere grants external provider credentials, platform API
permission, paid advertising/spend, business/brand publication authority,
network transport privileges, policy publication rights or customer-data access.

The current package is not production qualified. ooRexx execution tests were
not run here; the journal adapter has no fsync or concurrent-writer fencing.
