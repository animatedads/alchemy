## Never edit by hand

Every object here is generated from Body Slam's database of one commit. A new commit means a new run:

```
rexx bin/bodyslam.rex ingest /tmp/estate.db ROOT
gopher --profile sphere-authoring sphere edit create alchemy-estate --path OUT --title "Alchemy estate map"
rexx bin/bodyslam.rex sphere /tmp/estate.db OUT COMMIT ROOT
gopher --profile sphere-authoring sphere edit validate alchemy-estate --path OUT
```

(`bin/bodyslam.rex` is in `packages/oorexx_slam_v0.1`; `sphere` needs crypto v0.8.3, Runtime Reference v0.4 and the Foreign Runtime on `REXX_PATH` and `LD_LIBRARY_PATH`, for the SHA-256 in each provenance.)

## Using it

Install the pack and profile into LLM Gopher (`packs/alchemy-estate`, `profiles/alchemy-estate.json`), then:

```
gopher --profile alchemy-estate open estate.how-to-use
gopher --profile alchemy-estate open estate.family.oorexx_crypto
gopher --profile alchemy-estate exec corpus.record.lookup field=term value=oorexx_crypto corpus=estate-index
```
